# ⚽🏆 World Cup 2026 Predictor

> Because waiting until 2026 to know the winner is simply too long.

A full-stack football prediction platform that simulates the entire FIFA World Cup 2026, from the group stage to the final trophy lift.

Whether you're a data enthusiast, a football fanatic, or someone who still believes their national team is bringing the trophy home, this project is for you.

---

## 🎯 What Does It Do?

This application predicts:

* ✅ Every group stage match
* ✅ Final group standings
* ✅ The complete knockout bracket
* ✅ Round of 32 → Round of 16 → Quarter-finals → Semi-finals → Final
* ✅ Your future heartbreak when your favorite team gets eliminated

---

## 🤖 How Smart Is It?

The prediction engine combines:

* Team ratings (0–100)
* Recent match performance
* Goals scored & conceded
* Historical results
* A little football magic ✨

Unlike your friend who predicts every match based purely on vibes, this model actually uses data.

## 🚀 Installation

### Clone the Repository

```bash
git clone https://github.com/yourusername/world-cup-2026-prediction.git
cd world-cup-2026-prediction
```

### Install Dependencies

```bash
npm install
```

### Start the Backend

```bash
npm start
```

### Start the Frontend

```bash
ng serve
```

Open your browser and visit:

```text
http://localhost:4200
```

And begin predicting football history.
